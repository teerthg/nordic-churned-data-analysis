# nordic-churned-data-analysis
Customer churn analysis on Nordic ecommerce data using Python, Pandas, and Statistics.

Customer churn is one of the biggest challenges faced by ecommerce platforms. This project focuses on a churn analysis conducted on a real-world Nordic ecommerce dataset using Python and statistical techniques to derive actionable insights.

## 🔍 Project Objective
To analyze churned customers from Nordic ecommerce sales data and:
- Understand revenue trends
- Identify top churn indicators
- Perform exploratory statistical analysis
- Visualize actionable patterns

---

## 🧰 Tools & Libraries Used
- **Python**
- **Pandas**, **NumPy**
- **Matplotlib**, **Seaborn**
- **SciPy** (for hypothesis testing)
- **Jupyter Notebook** (for analysis)
- **Excel** (for pivot summaries)

---

## 📊 Key Insights
- 💰 Total Sales: ~9.75 Million NOK
- 📉 Churn Rate Peaks: Found in 2014–2016 period
- 🌍 Highest churn came from **United Kingdom** and **Germany**
- 📦 High-frequency small purchases were most prone to churn
- 📈 80% of revenue came from ~20% of customers (Pareto trend)
